# Chatbot Friend

Chatbot simple desarrollado como práctica del curso de Front-End, utilizando HTML, CSS y JavaScript.

**Sitio Publicado: (https://y4e1-png.github.io/Chatbot-Friend/)**

## Descripción

El chatbot consulta un objeto con respuestas predefinidas y muestra la conversación mediante burbujas que distinguen los mensajes del usuario y del bot.

## Funcionalidades

- Envío de mensajes mediante el botón o la tecla Enter.
- Respuestas con un retraso de 1,5 segundos.
- Mensaje de ayuda para entradas desconocidas.
- Limpieza del campo de texto después de enviar.
- Botón para borrar los mensajes visibles de la conversación.

## Tecnologías

- HTML para la estructura.
- CSS para los estilos.
- JavaScript vanilla para la interacción y las respuestas.

## Cómo utilizarlo

1. Descarga o clona el repositorio.
2. Abre `index.html` en un navegador.
3. Escribe un mensaje y pulsa Enter o el botón de envío.

No requiere instalar dependencias. La tipografía de Google Fonts necesita conexión a internet.

## Mensajes de ejemplo

- `hola`
- `como estas?`
- `adios`
- `que puedes hacer?`

Las entradas deben coincidir con alguna de las claves definidas en el objeto de respuestas. Algunas incluyen variantes de mayúsculas y signos.

## Archivos principales

- `index.html`: estructura de la interfaz.
- `styles.css`: diseño y estilos de las burbujas.
- `functions.js`: envío, consulta de respuestas y limpieza de mensajes.
- `assets/`: imagen del logo.
